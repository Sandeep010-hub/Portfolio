## 🛠 Technical Specification & Internal Stack

The portfolio is built on a high-performance stack optimized for edge delivery and instantaneous state transitions:

*   **⚡ Runtime**: Next.js 16 (Utilizing Turbopack for near-zero compilation latency)
*   **🎨 Styling**: Tailwind CSS v4 (Leveraging a bespoke, identity-aware color system)
*   **🎬 Orchestration**: Framer Motion (High-precision coordinate-based animations)
*   **🧠 State Control**: Zustand (Cross-component persistence of the identity engine)
*   **🛡 Deployment**: Vercel Edge Runtime (Globally distributed, sub-100ms cold starts)
*   **🌗 The Edison Bulb**: A custom-engineered coordinate-based circular ripple toggle using the **View Transitions API**.
